# 1-dars — IT KURSI: HTML Olamiga Kirish

Zamonaviy, interaktiv, 3D effektlarga ega EdTech ta'lim platformasi.

## 🚀 Texnologiyalar
- **React 19**
- **Vite**
- **Tailwind CSS**
- **CSS 3D Transforms** (`perspective`, `preserve-3d`, `rotateX`, `rotateY`, `translateZ`)
- **Sandboxed HTML Iframe** (Xavfsiz jonli natija ko'rish)
- **LocalStorage** (Progress va natijalarni saqlash)

## 📌 Asosiy Xususiyatlar
1. **Hero Section**: 3D qatlamli HTML vizualizatsiyasi (`<html>`, `<head>`, `<body>`, `<h1>`, `<p>`).
2. **Kirish Tajribasi**: "Internetdagi saytlar qanday yaratiladi?" savol-javobi va jonli "Salom, dunyo!" tajribasi.
3. **HTML Nima?**: Chuqur tushuntirish va "Uy analogiyasi" (HTML — karkas, CSS — bezak, JS — interaktivlik).
4. **HTML Teg Anatomiyasi**: Ochuvchi teg, kontent, yopuvchi teg va butun element qismlari interaktiv tahlili.
5. **3D HTML Hujjat Tuzilishi**: 3D DOM daraxti (`<!DOCTYPE>`, `<html>`, `<head>`, `<meta>`, `<title>`, `<body>`) va mini-testlar.
6. **Tipografika va Ro'yxatlar**: `<h1>`-`<h6>`, `<p>`, `<ul>`, `<ol>`, `<li>` bilan jonli ishlash.
7. **HTML Laboratoriyasi**: Qator raqamlari, sintaksis, namunalar, xavfsiz iframe preview va 4 bosqichli tekshiruv.
8. **"Xatoni Top" Chaqirig'i**: 5 ta professional coding challenge (xatolarni aniqlash va tuzatish).
9. **10 ta Amaliy Sinov**: Boshlang'ichdan mustaqil darajagacha dars davomidagi mashqlar.
10. **12 ta Yakuniy Test**: To'liq o'zlashtirish foizi va xato qilingan mavzular bo'yicha tavsiyalar.
11. **Mini-Loyiha**: "Men haqimda — mening birinchi veb-sahifam" va avtomatik 8 ta mezonli baholash.
12. **Doimiy Saqlash**: Login va serversiz, faqat qurilmadagi `localStorage` orqali progressni eslab qolish.

## 🛠 O'rnatish va Ishga Tushirish

```bash
# Repozitoriyani klonlash
git clone https://github.com/type-0713/1-dars.git

# Papkaga kirish
cd 1-dars

# Bog'liqliklarni o'rnatish
npm install

# Dev-serverni ishga tushirish
npm run dev
```
Brauzerda `http://localhost:5173/` yoki `http://localhost:5174/` orqali oching.
